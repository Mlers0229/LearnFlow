# AI 成本异常 Runbook

## 责任与告警

- 默认负责人：Platform；模型切换由 Agent 负责人批准。
- 告警：`LearnFlowDailyAiCostHigh`。
- Dashboard：Grafana `LearnFlow / AI Cost`。
- 初始演练阈值为滚动 24 小时估算费用 USD 25；生产上线前必须按已批准的日预算修改规则。

费用指标只在显式配置模型输入/输出单价且供应商返回 Usage 时产生，因此它是估算值，不能替代供应商账单。

## 首轮检查

1. 确认告警起止时间、模型、Token 类型、受影响功能和当前发布版本。
2. 对照供应商控制台用量；不得把 API Key、Prompt、回答或用户身份复制到工单。
3. 判断增长来自流量变化、请求放大、重试、循环调用、模型切换、单价配置错误或指标重复采集。
4. 检查 `learnflow_ai_model_calls_total`、`learnflow_ai_tokens_total`、降级率和任务重试，区分真实消耗与遥测问题。

## 处置

1. 指标重复采集：修复 Collector/Prometheus Target，不以重置计数器掩盖问题。
2. 非预期重试或循环：关闭对应入口或回滚版本，保留幂等任务和 Trace 证据。
3. 流量攻击或滥用：收紧认证用户限流和并发预算，优先保护普通 API。
4. 模型价格或配置异常：切换到已经评测通过的备用模型或规则降级；不得未经评测直接替换模型。
5. 预算接近耗尽：暂停非可靠性 AI 发布，并通知产品与财务负责人确认后续额度。

## 恢复与复盘

- 费用速率恢复后至少观察 2 小时，并核对供应商账单与本地估算偏差。
- 记录根因、估算与实付差异、被限制能力、用户影响和阈值调整依据。
- 如果 Usage 缺失，不补造 Token 或费用数据；单独告警遥测缺口并从供应商侧核验。

升级条件：预计当日超预算 25%、出现不明模型/Key 使用，或伴随身份滥用与数据泄漏迹象时，立即按安全事件升级并轮换凭证。
