# LearnFlow 生产基线盘点

- 盘点日期：2026-08-21
- 对应路线图：M0
- 盘点方式：仓库静态检查与本地构建验证

## 当前架构

| 组件 | 当前实现 | 主要缺口 |
| --- | --- | --- |
| Frontend | Vue 3 + Vite | 无测试/Lint；身份和角色保存在 `localStorage` |
| Backend | Spring Boot 3.3.4 + Java 17 + JPA | 无正式鉴权；无 Java 测试；信任客户端 `userId` |
| Agent | FastAPI + SQLAlchemy | 无内部认证；全开放 CORS；启动时自动建表 |
| Database | PostgreSQL 15 | 无版本化迁移；JPA 与 SQLAlchemy 共同管理 Schema |
| Deployment | Docker Compose | Agent 暴露宿主端口；单机；无灰度和恢复证据 |
| CI | 不存在 | 无自动构建、测试和安全门禁 |

## 已验证事实

- 后端 `mvn test` 构建成功，但当前没有测试源文件。
- 前端能够完成代码转换，但默认 `dist` 目录在本机被占用，基线构建在清空输出目录时失败；CI 将使用干净环境验证。
- Python 虚拟环境未安装 `pytest`，仓库也未声明开发测试依赖。
- 敏感本地配置已被 `.gitignore` 排除，当前 Git 索引未跟踪已知本地密钥文件。
- 工作区包含既有未提交和未跟踪文件，升级必须限定修改范围，不执行清理或重置。
