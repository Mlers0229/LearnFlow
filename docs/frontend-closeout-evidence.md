# 前端重做收尾证据

> 日期：2026-08-28
> 分支：`codex/docker-deploy`
> 范围：管理端批次 6 收口、全局会话过期提示、计划重排交互组件化

## 完成范围

- Agent 日志页升级为管理员工作台，支持 Trace ID、任务 ID、Agent、模型、状态和耗时筛选。
- 日志详情使用侧边抽屉展示服务端已脱敏、限长的请求与响应摘要，并支持关联任务跳转。
- 用户管理页支持用户名、角色、状态、注册时间筛选，以及创建账号、角色调整、禁用/恢复和临时密码生成。
- 管理员危险操作统一二次确认；前端阻止当前管理员降低或禁用自己的权限，并保证至少保留一个有效管理员。
- 增加全局会话过期对话框，重新登录时保留原页面返回地址。
- 将计划蓝图、校验、阶段与周节奏抽为独立 PlanOverviewPanel。
- 将计划顺延重排从浏览器原生 window.prompt 改为独立产品内对话框，支持顺延天数和可选原因。
- 删除已无引用的旧 Agent 日志页、旧用户管理页和旧用户管理 API 模块。

## 浏览器人工回归

使用隔离测试数据检查了 1440px 桌面与 390px 手机布局，确认：

- 用户列表、筛选、详情抽屉和危险操作确认可用。
- Agent 日志摘要、筛选、详情抽屉和 Trace 深链可用。
- 模拟 API 401 后，全局会话过期提示出现，并提供“稍后处理”和“重新登录”。
- 正常页面回归无浏览器控制台错误；会话过期场景仅出现预期的模拟 401。
