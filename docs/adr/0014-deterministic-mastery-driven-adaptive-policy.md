# ADR-0014：确定性的掌握度驱动自适应策略

- 状态：Accepted
- 日期：2026-08-23
- 决策范围：M4-LEARN-02

## 背景

Sprint 17 已建立可重放的 `mastery_profile`，但画像只用于展示，不会改变后续学习行为。直接把原始事件或用户身份交给模型会扩大隐私、越权、不可复现和 Prompt Injection 风险，也无法稳定进行对照评估。

## 决策

1. Spring Backend 是自适应策略的唯一决策方，策略版本为 `adaptive-v1`。
2. 仅当样本数不少于 2 且置信度不低于 0.25 时应用画像；否则保持固定策略。
3. 以稳定的 `CONTROL/ADAPTIVE` 分组支持 A/B 或准实验。分组写入 `adaptive_policy_assignment`，配置变化不改变既有用户分组。
4. Agent 只接收最多 3 个知识点的有界摘要、目标难度、复习间隔、优先级和练习方式；不接收用户 ID、原始事件、题目、答案、评论或 Prompt。
5. 策略同时作用于计划难度、复习间隔、资源排序、练习题型/知识点以及 Replan 的任务和时间比例。
6. 所有 LLM 与依赖失败路径仍执行相同的确定性规则；策略关闭、对照组或证据不足时回到既有行为。
7. `adaptive_decision` 只保存分类输出摘要和哈希，默认保留 90 天。指标与 Span 仅使用低基数标签。

## 取舍

- 第一版使用可解释阈值，不引入 DKT、强化学习或由模型自行决定难度。
- 规则能够证明行为差异，但在获得足够线上样本前不能宣称学习效果提升。
- 知识点仍使用 Sprint 17 的稳定键与受限展示名；后续可在保持契约的前提下升级 taxonomy。

## 回滚

- 设置 `LEARNFLOW_ADAPTIVE_ENABLED=false`，所有入口立即回到固定策略。
- 将 `LEARNFLOW_ADAPTIVE_PERCENTAGE=0` 可让新用户进入对照组；既有分组保持稳定，必要时由受控迁移切换实验键。
- 回滚应用版本不删除 V17 表和 `study_plan` 元数据列；旧版本可忽略这些扩展字段。
